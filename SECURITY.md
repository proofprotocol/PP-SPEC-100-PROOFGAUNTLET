# Security

## Reporting a flaw in the protocol

If you find a weakness in ProofGauntlet itself (a record that passes the Gate when it should not, a way to raise a Strength Rating without making a proof stronger, a way to hide a record from a Ranking Set, two conforming Raters that disagree, or an API behavior that leaks a supplied record), report it privately to the maintainer, Craig Thomas Ellrod, before public disclosure. Open a GitHub security advisory on this repository or contact the maintainer directly.

## Records

This repository never contains real records under test, canary contents, embargoed details, or exploit code. The conformance vectors describe no real product. Do not submit real records, keys, or embargoed details in issues or pull requests.
